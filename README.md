# MediCare AI Companion

MediCare is a medication schedule and reminder workspace. The public demo uses a fictional reminder and has no AI service, real medication entry or provider connection.

[Try the reminder demo](https://medicare-planner-demo.ranakaharian1.workers.dev/).

For a private installation, use Node.js 22 or newer. Run `npm ci` followed by `npm start`, then open http://127.0.0.1:4177/. See [developer setup](README-FIRST.md) for reminders, backups and optional services. The installation starts empty. Configure your own providers only if you need them.

This project still needs clinical review. Use it for recording a schedule, and consult a clinician or pharmacist for medication decisions.
